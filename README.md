### 一、项目介绍

基于SpringBoot的画师约稿管理系统分为前端用户端和后台管理系统。

用户端角色分为用户和画师。用户功能模块包括注册登录、查看画师作品列表、查看画师主页、查看作品详情、评论作品、预约画师、查看我的预约、编辑个人资料、修改密码等。画师功能模块包括查看我的预约、编辑个人资料、查看我的作品、发布作品等。

- 画师作品列表：查看各个画师的作品列表，也可以按分类、所属标签筛选画师作品。
- 作品详情：查看作品详细信息，如分类、简介、作品图等。
- 发表评论：可以在作品详情页查看评论列表及发表评论。
- 收藏喜欢：可以在作品详情页收藏或将该作品加入心愿单中。
- 预约画师：可以在每个作品详情页点击"预约作者"按钮来预约画师。
- 我的预约：显示我的预约列表，包括画师信息、约稿需求描述等。
- 编辑资料：编辑个人资料，如头像、昵称、个人简介等。
- 修改密码：修改当前登录用户的密码。

管理系统功能包括分类管理、标签管理、约稿管理、作品管理、用户管理、评论管理等。

- 分类管理：新增、编辑、删除及批量删除分类信息。
- 标签管理：新增、编辑、删除及批量删除标签信息。
- 约稿管理：查看约稿信息。
- 作品管理：新增、编辑、删除及批量删除作品信息。
- 用户管理：新增、搜索、编辑、删除及批量删除用户信息。
- 评论管理：删除及批量删除评论信息。
